# Runeforge profile artwork

Runeforge is Bryan Mc Namara's personal GitHub identity: a woodland workshop in plum and lavender, with a small peach ember above an anvil. It follows the visual family used by Lanternmote, Waynotch and Sealwick.

Use the personal name **Bryan Mc Namara** and handle **seraphalaric-beep**. Keep the artwork's plum shadows, lavender forms and restrained peach light. Use clear sans-serif supporting copy with the pixel display lettering. Preserve breathing room around the symbol and the name.
